# 💼 Job Portal Website

## 📌 Overview

This is a simple **Job Portal Website** developed to understand and practice basic web development concepts. It allows users to explore job-related pages and demonstrates the structure of a job portal system.

---

## 🚀 Features

* 👤 Basic User Interface for Job Portal
* 🔍 Job Listings Display
* 📄 Static Job Application Pages
* 🎨 Responsive Design using Bootstrap

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, Bootstrap
* **Backend:** PHP

---

## ⚙️ Setup Instructions

1. Install XAMPP
2. Place the project folder in:

   ```
   C:\xampp\htdocs\
   ```
3. Start **Apache**
4. Open browser and run:

   ```
   http://localhost/your-project-folder
   ```

---
